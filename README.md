# Кобзар — Всеукраїнська кухня

Концепт-сайт ресторану української кухні «Кобзар». Головна сторінка — стилізована
інтерактивна мапа регіонів України; клік на регіон відкриває меню зі стравами,
притаманними цьому краю.

## Структура

- `src/lib/regions.ts` — дані про всі 15 кулінарних регіонів (назва, страви,
  зона, колір).
- `src/lib/ukraine-map-data.ts` — реальні геометричні контури областей
  України (SVG-шляхи), згруповані по 15 кулінарних регіонах. Дані взято з
  [VictorCazanave/svg-maps](https://github.com/VictorCazanave/svg-maps)
  (CC BY 4.0).
- `src/components/UkraineMap.tsx` — інтерактивна SVG-мапа справжніх контурів
  України; кожен регіон підсвічується при наведенні та веде на своє меню.
- `src/components/RegionMenu.tsx` — шаблон сторінки меню регіону (стрічка-
  заголовок, картки страв, секція «Додатки»), світла/темна тема чергується
  по регіонах.
- `src/app/menu/[slug]/page.tsx` — динамічна сторінка меню для кожного
  регіону.

Дизайн меню «Полтавщина» (світла тема) та «Поділля» (темна тема) відтворює
надані референсні макети. Фотографій страв ще немає — замість них тимчасові
іконки-плейсхолдери (`src/components/DishImage.tsx`); реальні фото можна
підставити пізніше без зміни структури.

## Розробка

```bash
npm install
npm run dev
```

Відкрити [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm run lint    # eslint
```
